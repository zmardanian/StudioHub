# Physical Golden Chain Roadmap

## Stage A — software controls (implemented)
- inventory
- calibration evidence records
- certificate hashes
- expiry checks
- traceability graph
- environmental observations
- fail-closed readiness assessment

## Stage B — acquire and characterize hardware
- reference DAC
- reference ADC
- precision analyzer or equivalent independent reference
- low-distortion cabling/fixture
- clocking/reference strategy
- environmental sensors

## Stage C — external calibration
Obtain certificates from competent calibration providers for the quantities and ranges actually needed. Record certificate IDs, validity, uncertainty, conditions and traceability claims.

## Stage D — chain characterization
Measure loopback gain, frequency response, distortion, noise, crosstalk, timing and stability. Repeat over relevant levels/frequencies and environmental conditions.

## Stage E — uncertainty budgets
Build procedure-specific budgets from actual evidence. Include instrument calibration, repeatability, resolution, environmental effects, fixture effects, reference source uncertainty and relevant correlations.

## Stage F — inter-laboratory comparison
Measure a stable artefact with an independent competent laboratory and compare results using pre-defined comparison criteria.

## Stage G — quality system / accreditation path
If formal accreditation is required, implement the applicable ISO/IEC 17025 quality and technical system and engage the relevant accreditation body for the desired scope. The software cannot self-declare accreditation.
