# Traceability Policy

Software cannot manufacture metrological traceability.

A valid traceability record should identify the physical instrument, calibration certificate, calibration laboratory/provider, calibration date and validity, and the chain claimed by the certificate. The software stores these identifiers and refuses to interpret missing data as proof of traceability.

The eventual StudioHub laboratory should maintain:

1. instrument inventory;
2. calibration certificates;
3. calibration due dates;
4. reference standards;
5. environmental records where relevant;
6. measurement procedures;
7. uncertainty budgets;
8. verification/intercomparison records;
9. raw data and report hashes;
10. software version/revision used to create each report.
