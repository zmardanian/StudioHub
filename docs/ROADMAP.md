# Direction

StudioHub's next work should turn the current functional release candidate into a dependable daily engineering tool:

- Broaden clean-machine installation and launch coverage across supported Linux distributions.
- Keep project manifests, toolchain profiles, and evidence portable across machines.
- Expand capability-specific measurement coverage without turning measurements into subjective sound claims.
- Improve plugin host lifecycle coverage and retain actionable graphics-stack diagnostics.
- Make verification receipts straightforward to export and compare.
- Resolve the project-wide source license before accepting outside code contributions.

The larger ambition is to make Linux a first-class place to design, build, measure, and evaluate audio plugins. We believe StudioHub can soon become a game changer for Linux audio engineers; that is a goal, not a claim that the work is finished today.
